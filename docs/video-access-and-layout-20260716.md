# Видео: доступ и каркас страницы

Дата фиксации: 2026-07-16.

## Доступ

- Вкладка и страница `Видео` видимы всем пользователям.
- Общего тарифного запрета на видеостудию нет.
- Кнопка `Создать видео` всегда остаётся в Composer. Если тарифу не назначена
  подходящая модель, кнопка не исчезает, а показывает состояние `Нет модели`.
- Реальное ограничение выполняется матрицей видеомоделей в
  `Модели -> OpenRouter`: модель должна быть включена для режима и назначена
  тарифу пользователя.
- Backend повторно проверяет модель, режим, длительность, разрешение и формат
  перед отправкой задания. Клиентская видимость не считается защитой.

Поля `video_enabled` и `video_slots` сохранены в старом тарифном контракте
только для обратной совместимости со статистикой. Они не открывают и не
закрывают страницу и не участвуют в разрешении генерации.

## Каркас страницы

Видео использует общий паттерн студии:

`Composer -> Stage -> Actions -> History + Context`.

- На Full HD ширина Composer равна `440 px`, как у основной студии.
- Прокручиваются только настройки Composer. Главная кнопка остаётся видимой
  внизу панели и не перекрывает содержимое.
- Четыре режима расположены сеткой `2 x 2` с постоянными разделителями.
- Заголовок промпта: `Что происходит в кадре?`.
- Текст промпта использует Onest, нормальную насыщенность и размер `15 px`.
- Длительность компактна и не растягивается на всю ширину панели.
- Звук оформлен компактным switch без отдельной тяжёлой карточки.
- На телефоне первым показывается Stage, затем история и параметры результата,
  после чего Composer.

## Проверки

Автоматическая проверка `frontend/e2e-video-studio-layout.mjs` контролирует:

- Full HD `1920 x 1080` и браузерную высоту `1920 x 900`;
- 4K `3840 x 2160`;
- телефон `390 x 844`;
- отсутствие горизонтального переполнения;
- нахождение истории и действий внутри viewport;
- постоянную видимость главной кнопки;
- нормальную насыщенность текста промпта;
- видимую границу переключателя режимов;
- отсутствие тарифной блокировки вкладки `Видео`.
