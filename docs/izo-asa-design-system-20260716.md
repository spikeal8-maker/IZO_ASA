# Дизайн-система ИЗО АСА

Дата фиксации: 2026-07-16

Статус: обязательный общий норматив проекта. Это не описание одной страницы.

## Область действия

Норматив применяется к генерации изображений и видео, редактору, сборке из референсов, галерее, ленте, профилю, балансу и подписке, а также к мобильной, планшетной и компьютерной версиям, Telegram Mini App и MAX Mini App.

## Неизменяемое ядро

На всех страницах одинаковы цветовые токены, шрифт Onest, типографическая шкала, кнопки, поля, селекты, вкладки, иконки, радиусы, границы, состояния hover/focus/loading/disabled, токены, мобильная навигация и логика адаптивности.

Лаймовый `#C7F500` всегда означает главное действие, выбранный режим, активный инструмент, прогресс или дневные токены. Он не используется как случайный декор.

## Каркас рабочих инструментов

Общий паттерн генераторов:

`Composer -> Stage -> Actions -> History + Context`

- Composer: входные материалы и параметры.
- Stage: крупный результат.
- Actions: только основные действия с результатом.
- History: предыдущие версии.
- Context: промпт и настройки выбранной работы.

Для изображений Stage показывает изображение, для видео видеоплеер. Сценарии отличаются входными данными, но не визуальным языком.

## Уровни документации

1. Foundations: цвета, типографика, отступы, радиусы, сетка, глубина, иконки, motion, accessibility.
2. Components: кнопки, tabs, segmented control, textarea, select, slider, upload/reference cards, token indicator, history item, prompt context, bottom sheet, video controls.
3. Patterns: Composer, Stage, Context Shelf, состояния результата, загрузки, генерации, референсов и профессиональных параметров.
4. Pages: По тексту, По изображению, Сборка, Редактор, Видео, Галерея, Лента, Профиль.

Страница не создает новый компонент, если задача решается существующей системой.

## Основное визуальное правило

Пользовательский контент яркий и крупный. Интерфейс спокойный и нейтральный. Акцент один и функциональный.

- Фото и видео занимают максимум пространства.
- Кнопки не должны быть разноцветными.
- Текст не должен быть чрезмерно жирным.
- Рамка не ставится вокруг каждого блока.
- Декоративный неон не используется повсеместно.
- Панель не конкурирует с результатом.

## Типографика и геометрия

- Шрифт: Onest Variable.
- Основной текст: 400-450, 16-17 px на Full HD.
- Подпись: 450-500.
- Кнопка: 550-600, 14-15 px.
- Заголовок секции: 600, 16-18 px.
- Заголовок страницы: 620-650, 22-25 px.
- Метаданные: 12-13 px.
- Радиусы: 6, 10, 13, 17 px; bottom sheet 22 px.
- Контролы: 44-52 px; главный CTA 54-64 px.
- Иконка: 18-22 px.
- Touch target: минимум 44x44 px.

## Запрещено

- Новый акцентный цвет или отдельный шрифт для одной страницы.
- Эмодзи вместо иконок.
- Несколько зеленых CTA на одном экране.
- `font-weight: 800-900` для интерфейсного текста.
- Уменьшение текста ради вместимости.
- Неявный crop пользовательского медиа.
- Карточка внутри карточки без функциональной причины.
- Дублирование действия в нескольких местах.
- Технические параметры на основном уровне.
- Полноэкранное модальное окно для обычного промпта.
- Простое сжатие desktop-композиции вместо мобильной перекомпоновки.
- Изменение значения цветов между страницами.

## Итог

Один бренд, одна цветовая система, одна типографика, одна компонентная библиотека и одна логика рабочих пространств. Страницы отличаются задачами, но не ощущаются как разные продукты.
