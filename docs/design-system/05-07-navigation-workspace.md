# 5. Информационная архитектура
## 5.1. Верхний уровень продукта
| **Область**          | **Разделы**                                                          | **Задача**                    |
|----------------------|----------------------------------------------------------------------|-------------------------------|
| Создание изображений | По тексту · По изображению · Из нескольких                           | Получить новое изображение    |
| Редактор             | По эскизу · Заменить область · Расширить · Удалить фон               | Изменить изображение          |
| Видео                | Текст → видео · Изображение → видео · Начало и конец · По референсам | Создать ролик                 |
| Личная работа        | Галерея · Проекты · Пресеты                                          | Хранить и продолжать          |
| Социальный слой      | Лента                                                                | Публиковать и смотреть работы |
| Аккаунт              | Профиль · Подписка · Баланс                                          | Управлять доступом и оплатой  |

## 5.2. Глобальные режимы
На desktop верхние вкладки ДОЛЖНЫ быть видимы одновременно: По тексту, По изображению, Из нескольких, Редактор, Видео. Внутри «Видео» находятся четыре собственных режима. На mobile вкладки располагаются в горизонтальной ленте, но не уменьшаются до микротекста.

## 5.3. Состояние вкладки
- Промпт и исходники сохраняются при переходе.

- Результат и история режима сохраняются.

- Очистка выполняется только явным действием «Начать заново».

- Если работа открыта из истории, активируется режим, в котором она была создана.

# 6. Глобальная оболочка и навигация
## 6.1. Desktop header
| **Зона** | **Содержимое**            | **Правило**                                          |
|----------|---------------------------|------------------------------------------------------|
| Слева    | Логотип ИЗО ACA, Лента    | Лента может использовать фиолетовый брендовый акцент |
| Центр    | 5 рабочих вкладок         | Активная вкладка лаймовая                            |
| Справа   | Галерея, токены, профиль  | Галерея выглядит как кнопка, не как висящий текст    |
| Токены   | Дневные 8/10, Премиум 120 | Не показывать искусственную общую сумму              |

## 6.2. Mobile header
- Логотип и два баланса остаются сверху.

- Если Профиль есть в нижней навигации, аватар в шапке не дублируется.

- Глобальная нижняя навигация: Создать, Галерея, Лента, Профиль.

- В редакторе нижняя навигация скрывается.

## 6.3. Активное состояние вкладки
Активная вкладка имеет лаймовую заливку, тёмный текст и отсутствие лишнего glow. Неактивные вкладки используют Surface 1/2 и Text Secondary. Вертикальные разделители не должны превращать вкладки в таблицу.

# 7. Рабочая архитектура desktop

## 7.1. Composer
- Ширина Full HD: 410–430 px.

- На 1366 px: 360–390 px.

- На 2K/4K: 460–560 px через clamp().

- Прокручивается только центральное содержимое.

- Заголовок и CTA остаются на месте.

- CTA не перекрывает формат и параметры.

## 7.2. Stage
- Занимает максимум площади.

- Медиа показывается целиком через object-fit: contain.

- Верхняя служебная панель не используется.

- Под медиа остаются только главные действия.

- Full screen и fit могут быть иконками в углу медиа.

## 7.3. Actions
Для изображений и видео базовые действия: Скачать и Поделиться. Редактировать показывается только там, где продолжение действительно существует. Все системные действия - Добавить в проект, Опубликовать, Удалить, Начать заново - находятся в контекстном меню выбранной работы.

## 7.4. Context Shelf
- История занимает большую часть ширины.

- Подписи форматов под миниатюрами не нужны; формат читается по форме.

- Промпт ограничен 2–3 строками.

- Разворачивание меняет только нижнюю полку.

- История прокручивается колесом и свайпом.
