## 19.1. По тексту
> **1.** Промпт.
>
> **2.** Голос / Улучшить / Шаблоны / Идея.
>
> **3.** Стиль.
>
> **4.** Формат.
>
> **5.** Параметры генерации.
>
> **6.** Один CTA.

После генерации на mobile открывается результат с редактируемым промптом и кнопкой «Сгенерировать ещё». Это поддерживает повторное потребление токенов без лишней навигации.

## 19.2. По изображению
- Компактный источник с полным превью.

- Крестик на изображении.

- Сила изменения.

- Промпт.

- В Stage - интерактивный До/После.

## 19.3. Из нескольких
- 2–4 reference cards.

- object-fit: contain.

- Роль и объяснение.

- Дополнительные пожелания.

- Сохранить набор как пресет - профессиональная опция.

## 19.4. Действия результата
Основной ряд: Скачать, Поделиться. Редактировать может быть третьей командой для изображений, если экран сохраняет достаточную площадь Stage. Остальные действия - в меню Prompt Context.

# 20. Страница генерации видео
> **Иллюстрация:** Рисунок 10. Видео использует тот же каркас, но собственные входные сценарии.

Рисунок 10. Видео использует тот же каркас, но собственные входные сценарии.

## 20.1. Четыре режима
| **Режим**           | **Обязательные данные**    | **Главное отличие**                          |
|---------------------|----------------------------|----------------------------------------------|
| Текст → видео       | Описание сцены             | Создать сцену без исходника                  |
| Изображение → видео | Кадр + описание движения   | Оживить изображение                          |
| Начало и конец      | 2 ключевых кадра + переход | Управляемая трансформация                    |
| По референсам       | 2–4 материала + роли       | Собрать ролик из персонажа, окружения, стиля |

## 20.2. Composer видео
- Режимы располагаются сеткой 2×2.

- Промпт называется «Что происходит в кадре?».

- Модель и длительность видимы.

- Формат и качество видимы.

- Звук - switch.

- FPS, камера, движение, свет, seed - профессиональные настройки.

## 20.3. Плеер
- Play/pause, время, progress, volume, fullscreen.

- Надпись «Предпросмотр / Готово» не требует отдельной полосы.

- Под плеером: Скачать и Поделиться.

- Poster history показывает длительность в бейдже.

## 20.4. Mobile result
> **1.** Крупный плеер.
>
> **2.** Скачать и Поделиться.
>
> **3.** Редактируемое описание.
>
> **4.** Улучшить.
>
> **5.** Предыдущие ролики.
>
> **6.** Создать ещё с ценой токена.

## 20.5. Генерация
Показываются реальные этапы backend. Если API возвращает очередь и приблизительное время, они отображаются. Поддельный линейный процент запрещён.

# 21. Редактор
## 21.1. Архитектура desktop
| **Зона**   | **Содержимое**                        |
|------------|---------------------------------------|
| Top bar    | Назад, Undo, Redo, сравнение, экспорт |
| Left tools | Кисть, ластик, маска, move, zoom      |
| Canvas     | Изображение/эскиз, pan/zoom           |
| Properties | Размер, жёсткость, режим, модель      |
| Prompt bar | Описание и применить                  |

## 21.2. Режимы
- По эскизу: рисунок → изображение.

- Заменить область: маска + описание.

- Расширить: направления и outpainting.

- Удалить фон: автоматический результат, ручное уточнение по необходимости.

## 21.3. Mobile editor
- Canvas занимает максимум.

- Инструменты в горизонтальной ленте.

- Undo/Redo всегда доступны.

- Глобальная bottom nav скрыта.

- Prompt bar открывается без потери холста.

# 22. Галерея, лента, профиль и проекты
## 22.1. Галерея
- Фильтры: Все, Созданные, Загруженные, Редактор, Видео.

- Карточки сохраняют пропорции.

- Действия появляются при выборе, а не постоянно.

- Поиск по названию и промпту.

## 22.2. Лента
- Фиолетовый допустим как социальный акцент.

- Работа остаётся главным объектом.

- Лайк, автор, использовать настройки, открыть работу.

- Лента не наследует рабочие панели Composer.

## 22.3. Профиль
- Два баланса токенов.

- Подписка и дата действия.

- Пресеты и проекты.

- Настройки платформы и доступность.

## 22.4. Проекты
Проект - контейнер связанной работы: исходники, генерации, видео, редактор и публикации. Он не должен смешиваться с историей текущего режима.
