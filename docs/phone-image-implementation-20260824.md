# PHONE-IMAGE-001A — нативное создание изображений

**Дата:** 2026-08-24
**Статус:** `CODE COMPLETE; NOT DEPLOYED; LIVE QUALITY ACCEPTANCE PENDING ROLLOUT`

## Граница пакета

Первый ограниченный пакет раздела изображений переносит основной пользовательский
путь из временного Phone runtime в React: создание по описанию, изменение и
совмещение до четырёх исходников, рисование, стили, шаблоны, форматы, разрешения,
модели, история и просмотр результата.

Второй ограниченный пакет добавляет маску, расширение, удаление фона,
face-reference и публикацию. Эти функции отделены в собственный компонент, а
их payload проверяется независимо от основного создания.

## Реализовано

- маршруту `/phone/image` принадлежит нативный React workspace без iframe;
- начальные параметры: квадрат `1:1`, качество `HD`;
- набор разрешений перестраивается под выбранное соотношение сторон;
- `4K` остаётся видимым, но блокируется capability модели;
- модели и разрешённые режимы поступают с действующего `/api/model-access`;
- генерация использует `/api/generate`, а состояние и восстановление — общий
  `/api/phone/v1/jobs/{id}`;
- результат полностью помещается в preview (`object-fit: contain`);
- двойное нажатие открывает fullscreen, повторное меняет масштаб, поддержаны
  pinch и перемещение увеличенного изображения;
- реализованы компактные действия скачать, поделиться, оживить и очистить;
- история загружается из пользовательской галереи и сохраняет реальные пропорции;
- рисовальный холст соответствует выбранному формату и открывается на весь экран;
- маска рисуется поверх исходного изображения и отправляется отдельным PNG;
- расширение принимает поля с четырёх сторон и рассчитывает безопасный размер;
- удаление фона запускает настоящий режим `remove_background`;
- лицо является ролью второго референса, а ползунок 25–100% управляет силой
  установленной качественной LoRA; модель не заменяется и не выгружается UI;
- результат можно отправить в ленту через действующий publication endpoint;
- стили используют действующий каталог: первыми идут Фото, Аниме, Комикс, Неон;
  удалённые владельцем стили не возвращены;
- дневная стоимость выделяется жёлтым, основная — фиолетовым общим token helper.

## Проверка

- `npm --prefix frontend run test:phone-image` — 4/4;
- `npm --prefix frontend run lint` — успешно;
- production build с release label — успешно;
- Playwright mobile flow — `390x844` и `430x932`, пять deep links, без iframe и
  horizontal overflow; дополнительно проверены генерация, история, preview close
  fullscreen viewer, инструменты редактора и публикация;
- отдельный browser flow загрузил реальный JPEG, нарисовал маску указателем и
  подтвердил POST `mode=inpaint` с PNG-маской (50 570 байт).

Проверка использует контролируемые ответы API и не расходует provider-баланс.
Содержательное качество маски, прозрачности, outpaint и силы лица на реальных
результатах, а также live ComfyUI/OpenRouter вызов будут иметь
отдельный статус `OPERATIONALLY VERIFIED` только после разрешённого rollout.
