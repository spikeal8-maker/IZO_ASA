# PHONE-IMAGE-001A — нативное создание изображений

**Дата:** 2026-08-24
**Статус:** `CODE COMPLETE; NOT DEPLOYED; LIVE GENERATION ACCEPTANCE PENDING ROLLOUT`

## Граница пакета

Первый ограниченный пакет раздела изображений переносит основной пользовательский
путь из временного Phone runtime в React: создание по описанию, изменение и
совмещение до четырёх исходников, рисование, стили, шаблоны, форматы, разрешения,
модели, история и просмотр результата.

Полный `PHONE-IMAGE-001` этим пакетом не закрыт. Маска, расширение, удаление фона
и face-reference оформляются следующим отдельным пакетом, чтобы их качество и
payload проверялись независимо.

## Реализовано

- маршруту `/phone/image` принадлежит нативный React workspace без iframe;
- начальные параметры: квадрат `1:1`, качество `HD`;
- набор разрешений перестраивается под выбранное соотношение сторон;
- `4K` остаётся видимым, но блокируется capability модели;
- модели и разрешённые режимы поступают с действующего `/api/model-access`;
- генерация использует `/api/generate`, а состояние и восстановление — общий
  `/api/phone/v1/jobs/{id}`;
- результат полностью помещается в preview (`object-fit: contain`);
- двойное нажатие открывает fullscreen, повторное меняет масштаб, поддержаны
  pinch и перемещение увеличенного изображения;
- реализованы компактные действия скачать, поделиться, оживить и очистить;
- история загружается из пользовательской галереи и сохраняет реальные пропорции;
- рисовальный холст соответствует выбранному формату и открывается на весь экран;
- стили используют действующий каталог: первыми идут Фото, Аниме, Комикс, Неон;
  удалённые владельцем стили не возвращены;
- дневная стоимость выделяется жёлтым, основная — фиолетовым общим token helper.
