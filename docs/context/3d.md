# Context: 3D

## Назначение

Эта карточка описывает текущий provider-neutral 3D contract boundary.
Она не означает наличие production 3D generation.
Текущее состояние capability обязано оставаться fail-closed.

## Текущее состояние: отключено / contract-only

- provider-neutral contract = EXISTS
- fake-provider contract tests = EXISTS
- production route = NOT IMPLEMENTED
- production provider adapter = NOT IMPLEMENTED
- durable production 3D flow = NOT IMPLEMENTED
- paid quality benchmark = NOT RUN
- capability = DISABLED / CONTRACT-ONLY

Нельзя превращать наличие типов и fake tests в утверждение о рабочем продукте.
Нельзя писать, что Meshy или Tripo интегрированы.
Нельзя писать, что пользовательский route генерирует реальные 3D assets.

## Владение

- `backend/app/services/phone_3d_contracts.py` владеет provider-neutral contracts.
- Contract определяет request, quote, job, asset и provider protocol.
- Production adapter отсутствует в текущем grounded scope.
- Production HTTP route отсутствует в текущем grounded scope.
- Durable orchestration/storage отсутствуют в текущем grounded scope.
- Economics пересекается с `billing-payments`, но эта карточка не реализует settlement.
- Image input semantics пересекаются с `image-generation`.

## Основные точки входа

Единственный production-source path этой карты:
`backend/app/services/phone_3d_contracts.py`.

Он определяет:
- `ThreeDRequest`;
- `ThreeDQuote`;
- `ThreeDAsset`;
- `ThreeDJob`;
- `ThreeDProvider`;
- status normalization;
- safe public error;
- mobile asset budgets.

## Request contract

Поддерживаются contract modes:
- `text_to_3d`;
- `image_to_3d`.

Image-to-3D требует owned input image.
Request требует durable idempotency key.
Output format и geometry budgets валидируются contract layer.
Это contract validation, а не доказательство работающего provider.

## Provider contract

`ThreeDProvider` задаёт quote/create/get/cancel protocol.
Это интерфейс будущего adapter boundary.
Fake provider в tests доказывает только совместимость contract shape.
Он не доказывает production connectivity или provider quality.

## Asset contract

Provider result обязан использовать HTTPS asset URL.
Mobile-ready property ограничивает format/bytes/triangles/texture.
Эти budget checks защищают consumer boundary.
Они не означают, что asset реально создан внешним provider.

## Границы

- Не создавать live provider calls в этом package.
- Не добавлять production route скрыто через context work.
- Не добавлять provider credentials.
- Не включать capability flag.
- Не добавлять durable job storage.
- Не связывать contract с billing settlement без отдельного implementation package.
- Не считать fake provider operational verification.

## Связь с image-generation

Image input ownership может требовать проверку `image-generation`.
3D contract не забирает ownership обычной image generation queue.
Owned image requirement должен сохраняться при будущем adapter work.

## Связь с billing-payments

Quote содержит provider credits и charged tokens contract fields.
Это ещё не durable charge и не settlement.
Любая реальная экономика требует `billing-payments` context и отдельного high-assurance scope.
