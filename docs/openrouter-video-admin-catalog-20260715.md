# OpenRouter video: каталог в админке

Дата: 2026-07-15

Статус: первый этап готов. Каталог доступен только для анализа; пользовательская видеогенерация еще не подключена.

## Что реализовано

- Backend получает модели из отдельного OpenRouter endpoint `GET /api/v1/videos/models`.
- Ответ нормализуется в `backend/app/integrations/openrouter.py`; одна битая строка не ломает весь каталог.
- Каталог кешируется на 6 часов тем же сроком, что и каталог возможностей изображений.
- `GET /api/admin/models-page` отдает `openrouter.videoCatalog`, ошибку загрузки и имя источника.
- В `Админ -> Модели -> OpenRouter` появился раскрывающийся блок `Видео OpenRouter`.
- Модели разделены на сценарии: по тексту, по изображению, по первому и последнему кадру, по референсам.
- Для каждой модели видны длительности, разрешения, пропорции, поддержка кадров, аудио, seed, параметры и опубликованные цены.

## Правила классификации

| Сценарий | Проверяемый признак |
|---|---|
| По тексту | модель присутствует в специализированном video endpoint |
| По изображению | `supported_frame_images` содержит `first_frame` |
| Первый и последний кадр | присутствуют `first_frame` и `last_frame` |
| По референсам | описание модели содержит явное упоминание reference-to-video или reference images |

Последний сценарий помечен в интерфейсе как предварительный: текущий каталог OpenRouter не отдает отдельное структурированное поле с максимальным числом референсов. Перед включением такой модели нужен контрактный живой тест.

## Цены

`pricing_skus` сохраняется без потери ключей. Значения с префиксом `cents_per_` переводятся из центов в доллары для отображения. Остальные SKU показываются как опубликованные OpenRouter ставки. Это еще не пользовательская токенная цена: тариф, маржа, резервирование и возврат токенов будут добавлены вместе с video job pipeline.

- Живой каталог 2026-07-15: 16 моделей; 15 со стартовым кадром; 10 с первым и последним кадром; 6 с описанными референсами.
- Авторизованный live smoke админки: блок загрузился, группы раскрываются, каталог не заменяет и не скрывает каталог моделей изображений.

Общий `npm run build` на момент проверки блокировали две параллельные незавершенные правки вне этого пакета: неиспользуемые `error` в `frontend/src/main.tsx` и `FeedPublication` в `frontend/src/newUi.tsx`.
