# PHONE-AUDIO-001A — мобильная запись и распознавание речи

**Дата:** 2026-08-24

**Статус:** `PARTIAL CODE COMPLETE; NOT DEPLOYED; STT UI VERIFIED WITH FAKE PROVIDER`

## Реализовано

- нативный маршрут `/phone/audio` вместо общей заглушки;
- запись строго при удержании кнопки с явной анимацией и таймером;
- автоматическая остановка при отпускании или отмене касания;
- загрузка WebM, OGG, MP3, M4A и WAV до серверного лимита 8 МБ;
- реальный защищённый `POST /api/tools/transcribe` и выбранная администратором
  цепочка Qwen/Ollama/OpenRouter;
- результат распознавания, копирование, плеер, повтор, скачивание и удаление;
- компактная история до 12 записей в рамках открытого сеанса;
- доступность страницы управляется серверным Phone manifest;
- серверная ошибка показывается продуктовым текстом, без технической трассировки.

## Намеренно не имитируется

Следующие части полного контракта ещё не реализованы и поэтому не выдаются
пользователю за работающие:

- text-to-speech и каталог разрешённых голосов;
- серверная аудиоистория и аудиогалерея после перезагрузки;
- токеновый quote/settle/refund для TTS;
- передача сохранённой аудиодорожки в видеоредактор;
- музыка, клонирование голоса и очистка записи.

Для TTS выбран технически совместимый путь через официальный OpenRouter
`/api/v1/audio/speech`, но подключение требует отдельного серверного адаптера,
модели/голосов в админке, приватного хранения, экономики и fake-provider tests.

## Проверка

- `npm --prefix frontend run test:phone-audio` — 2/2;
- `python -m pytest backend/test_phone_platform.py -q` — 4/4;
- frontend lint и production build — успешно;
- Playwright на `390x844` и `430x932`: прямой маршрут, загрузка WAV, POST
  распознавания, текст, плеер и действия; горизонтального overflow нет.

Тестовый провайдер не расходует деньги и не отправляет пользовательское аудио
внешнему сервису. Реальный микрофон, качество распознавания и внешний provider
получат статус `OPERATIONALLY VERIFIED` только после отдельного rollout.

## Rollback

Пакет не меняет production DB/media, службы, AdGuard VPN, FRP, VPS, DNS, GPU или
секреты. Откат ограничен Phone frontend и значением доступности аудио в manifest.
