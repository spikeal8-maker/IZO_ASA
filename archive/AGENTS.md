# Правила работы с архивом IZO_ASA

Этот каталог хранит только исторические свидетельства. Действующие правила,
порядок чтения и активные задачи определяются корневым `AGENTS.md`,
`AI_START_HERE.md` и `docs/NOW.md`.

- Не использовать документы архива как актуальные спецификации, релизные инструкции или backlog.
- Не читать весь архив по умолчанию: открывать только конкретный файл по ссылке из действующей задачи или при историческом расследовании.
- Не восстанавливать устаревшие планы в `docs/` и не изменять продукт/production на основании старого отчёта.
- Содержимое архивных документов сохраняется побайтово; для корректного восстановления пользоваться исходным SHA из архивного реестра.
